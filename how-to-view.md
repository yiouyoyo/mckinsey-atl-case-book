# How to View the HTML Files as a Webpage

The HTML files in this repo (like `mckinsey/case type.html`) are interactive webpages — but GitHub shows them as raw code by default. Here are two easy ways to see them rendered properly.

---

## Option 1 — GitHub Pages (recommended — gets you a shareable link)

This turns the repo into a live website so you can open any HTML file in your browser with a real URL.

1. Go to your repo on GitHub: `github.com/yiouyoyo/mckinsey-atl-case-book`
2. Click **Settings** (top menu bar of the repo)
3. In the left sidebar, click **Pages**
4. Under "Build and deployment", set Source to **Deploy from a branch**
5. Set the branch to **main** and the folder to **/ (root)**, then click **Save**
6. Wait 1–2 minutes. GitHub will show you a URL at the top of the Pages settings — it will look like `https://yiouyoyo.github.io/mckinsey-atl-case-book/`
7. To open the case type file specifically, add the path to that URL:
   `https://yiouyoyo.github.io/mckinsey-atl-case-book/mckinsey/case%20type.html`

You can bookmark or share that link — it will always show the latest version from the repo.

---

## Option 2 — Download and open locally (no setup required)

Use this if you just want to view it quickly on your own computer.

1. Go to `github.com/yiouyoyo/mckinsey-atl-case-book/blob/main/mckinsey/case%20type.html`
2. Click the **Download raw file** button (the down-arrow icon near the top right of the file view)
3. Save the file anywhere on your computer
4. Find the saved file in your Downloads folder
5. Double-click it — it will open directly in your web browser as a formatted webpage

Note: this is a local copy only. If the file is updated in the repo later, you would need to download it again.

---

That's it. Option 1 is better if you want a permanent link to share. Option 2 is faster if you just want to take a quick look.
