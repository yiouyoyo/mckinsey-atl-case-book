## How to use

- Browse the folder for the firm you're prepping for (e.g. `mckinsey/`, `deloitte/`)
- Each folder contains case frameworks, playbooks, and industry guides for that firm
- `resources/` contains links to external case books and reference materials

## Structure

\`\`\`
mckinsey/     McKinsey case frameworks and guides
deloitte/     Deloitte case materials
resources/    External case book links and references
